# Lifeline Lahore — Blood Donor Availability Matcher

A blood donor matching platform for Lahore, Pakistan. Donors register their blood type and area; searchers find eligible matches and get notified via SMS and email.

## Architecture

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript 5
- **Database**: PostgreSQL 17 via Prisma ORM
- **Cache/Session**: Upstash Redis (OTP storage, rate limiting, session budgets)
- **SMS**: Twilio
- **Email**: SendGrid
- **Auth**: JWT-based session tokens (jose)
- **Validation**: Zod 4
- **Testing**: Vitest + Testing Library
- **Deployment**: Vercel (recommended) / Docker

## Prerequisites

- Node.js 24+
- PostgreSQL 17+
- Redis 7+ (or Upstash account)
- Twilio account (SMS)
- SendGrid account (email)

## Getting Started

### 1. Clone and install

```bash
git clone <repo-url> && cd blood-donor-app
npm install
```

### 2. Environment setup

```bash
cp .env.example .env
# Edit .env with your credentials
```

### 3. Database setup

```bash
npx prisma generate
npx prisma db push
```

### 4. Start dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

With `SKIP_OTP_VERIFICATION=true` (default in dev), OTP codes are logged to the console instead of sent via SMS.

## Project Structure

```
app/                 # Next.js App Router pages and Server Actions
  actions/           # Server Actions (register, search, OTP, etc.)
  components/ui/     # Reusable UI components
  manage/            # Self-service dashboard
  register/          # Donor registration flow
  search/            # Search flow
  api/health/        # Health check endpoint

lib/                 # Application logic
  domain/            # Business logic (matching, eligibility, OTP, rate-limiting, etc.)
  infra/             # Infrastructure adapters (Prisma, Redis, Twilio, SendGrid, JWT)
  validation/        # Zod input schemas
  presentation/      # UI labels

prisma/              # Database schema
scripts/             # Utility scripts (cleanup, load testing)
```

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | Health check (DB + Redis) |

All other operations use Next.js Server Actions (POST via form/JSON).

## Key Features

- **Donor Registration**: Name, phone, blood type, areas, last donation date
- **OTP Verification**: 6-digit code via SMS, 5-minute TTL, rate-limited
- **Eligibility Computation**: Derived at query time (90-day cooldown)
- **Search**: By blood type + area, with nearby area expansion
- **Notifications**: SMS (Twilio) + email (SendGrid) to matched donors
- **Self-Service**: Update donation date, delete registration
- **Rate Limiting**: Per-IP sliding window across all sensitive endpoints

## Docker

```bash
docker compose up --build
```

This starts PostgreSQL, Redis, and the app. OTP verification is skipped in Docker dev mode.

## Deployment

### Vercel (recommended)

Connect your repo to Vercel, set environment variables, and deploy. The `vercel.json` is auto-generated by the framework.

### Docker

```bash
docker build -t blood-donor-app .
docker run -p 3000:3000 --env-file .env blood-donor-app
```
